DAR GLOBAL + WASALT CHATBOT PROJECT FLOW AND CURRENT PROGRESS
=================================

1. PROJECT GOAL

The goal is to build a chatbot that can answer questions using publicly
available information from two real-estate websites:

-   DarGlobal
-   Wasalt

The planned system has these main parts:

1.  Collect public website data.
2.  Clean and prepare the collected data.
3.  Split long text into smaller chunks.
4.  Convert chunks into vector embeddings.
5.  Store embeddings in a FAISS vector database.
6.  Use LangGraph to control the chatbot workflow.
7.  Use an LLM through an OpenAI-compatible API such as OpenRouter.
8.  Expose the chatbot through FastAPI.
9.  Provide a simple web chat interface.
10. Test, package, and deploy the application.

The project is being developed on Windows using PowerShell and Python.

confused.

B)  scraper.py This is the smaller initial scaffold scraper. It has

placeholder file, and it is not the main large-scale crawl output.

The real DarGlobal dataset is data/full_dataset.jsonl.

6. INGESTION CODE: REVIEWED, NOT YET FIXED OR RUN

The current ingest.py was inspected.

It currently:

-   Reads data/pages.jsonl.
-   Expects each record to contain url, title, text, and optionally
    site.
-   Uses RecursiveCharacterTextSplitter.
-   Uses chunk size 800 characters and overlap 100 characters.
-   Uses the embedding model BAAI/bge-small-en-v1.5 through FastEmbed.
-   Creates a FAISS vector store.
-   Saves the index to data/index.

The main issue is a data-format mismatch:

The real DarGlobal JSONL file is data/full_dataset.jsonl and has fields:
id, company, category, title, text, source_url.

But ingest.py currently reads data/pages.jsonl and expects a field named
“url”. The real dataset uses “source_url”.

Therefore, the current ingest.py cannot yet correctly index the verified
DarGlobal dataset without being updated.

The two placeholder records in data/pages.jsonl are not sufficient for
building the real project index.

Do not run ingestion until the loader is updated to support the actual
DarGlobal and Wasalt dataset formats and their output paths.
